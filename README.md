A make.fun entry for [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

`main.py` writes one sentence explaining the modern internet to a time traveler from 1800 to `/output/entry.txt`, using only images a person from 1800 could hold in their head — a road, a library, a post office:

> Picture a road from your own door to one vast library and post office shared by the whole world, where letters arrive before the ink dries and any book you wish for opens at once.

Run it with `python3 main.py`.
